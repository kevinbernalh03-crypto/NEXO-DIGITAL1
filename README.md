# Nexo Digital 📰

## Periódico Digital

Nexo Digital es una aplicación de periódico digital desarrollada como proyecto
académico y adaptada para dispositivos móviles.

## Descripción

La aplicación permite consultar noticias organizadas por categorías,
visualizar artículos, realizar búsquedas y acceder a diferentes contenidos
desde una interfaz diseñada para dispositivos móviles.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Diseño responsive
- AppGeyser

## Funcionalidades

- 📰 Visualización de noticias
- 🔎 Búsqueda de artículos
- 📂 Organización por categorías
- ⭐ Guardado de contenidos
- 📝 Publicación de artículos
- 📱 Diseño adaptable a dispositivos móviles
- 💾 Almacenamiento local
- 📚 Manual de usuario
- 💻 Repositorio de código
- 📸 Evidencias de funcionamiento
- 👤 Prueba de usuario

## Impacto del proyecto

Nexo Digital facilita el acceso organizado a información periodística
mediante una interfaz digital sencilla y adaptable a dispositivos móviles.
El proyecto también permite aplicar conocimientos de desarrollo web,
diseño de interfaces y programación JavaScript.

## Evidencias

El proyecto incluye evidencias del desarrollo y una prueba de usuario
realizada durante el proceso de implementación.

## Proyecto académico

Desarrollado como parte del proceso de formación en el SENA.
